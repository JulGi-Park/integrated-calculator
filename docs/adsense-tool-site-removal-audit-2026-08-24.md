- 네 계산기에는 다음 의사결정으로 이어지는 관련 계산기 링크가 생겼다.
- 결과 해석 제목이 계산기별 질문을 직접 답하도록 구체화됐다.
- 잘못된 URL에서도 사이트 설명과 복구 경로를 제공한다.

### 검색엔진·AdSense 관점

- 공개 URL 30개와 계산기 21개가 하나의 목록에서 sitemap과 광고 허용 범위를 공유한다.
- 정책·운영·404 화면에는 AdSense 연결 스크립트가 실행되지 않는다.
- canonical·JSON-LD 절대 URL의 후행 슬래시가 일치한다.
- 모든 색인 URL은 고유 title, description, canonical, H1을 가지며 내부 링크는 실제 공개 경로만 가리킨다.
- 404는 `noindex, follow`이며 광고 슬롯과 AdSense 연결이 없다.

## 7. 삭제·병합·noindex 결정

| 대상 | 결정 | 이유 |
|---|---|---|
| 공개 30 URL | 유지/index | 각 URL의 독립 목적과 Publisher Layer 확인 |
| 공개 계산기 21개 | 유지/index | 입력 전후에도 설명·예시·해석·한계·출처가 존재 |
| 검색/태그/테스트/개발/결과 URL | 해당 없음 | 공개 라우트 자체가 없음 |
| 404 및 미등록 경로 | noindex/follow | 검색 결과 가치가 없고 복구 링크만 제공 |
| 쿼리·해시 변형 | canonical URL로만 내부 연결 | 별도 색인 URL을 만들지 않음 |
