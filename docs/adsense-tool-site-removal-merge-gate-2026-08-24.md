## 3. Boilerplate와 링크 진단

- 5단어 shingle Jaccard 최고 유사도: 주휴수당↔부가세 0.89%.
- 35자 이상 동일 문장이 3개 이상 계산기에 반복된 사례: 0건.
- 모든 페이지에 같은 관련 계산기 목록을 붙인 패턴: 없음. 페이지당 1~4개이며 계산 결과 다음 판단과 연결된다.
- 계산기 산출물의 외부 HTTPS 링크는 GA/AdSense 연결 2개를 포함해 78개 고유 URL이다. 근거 링크는 NTS, NPS, NHIS, MOEL, Work24, FSC, BOK, 법령정보센터, 지자체 등 관련 공식 기관으로 구성된다.
- 자동차 유지비의 “개별 보험사·정비업체” 항목이 자기 페이지를 출처처럼 링크하던 문제는 링크 없는 개별 조건 확인 항목으로 수정했다.

유사도 수치는 승인 점수가 아니라 수동 판독 대상 선별용이다. 글자 수·문단 수·링크 수로 READY를 판정하지 않는다.

## 4. 발견 및 수정한 Merge blocker

1. 연봉 계산기의 건강보험 총 보험료 상한을 근로자 부담 상한으로 잘못 저장해 다시 2로 나누던 오류를 총액 9,183,480원으로 수정했다. 근로자 상한은 4,591,740원이다.
2. 4대보험 계산기의 장기요양보험료가 반올림된 13.14%를 사용해 연봉 계산기의 공식 비율식과 최대 21원 달랐다. `건강보험료 × 0.9448% ÷ 7.19%`로 통일했다.
3. 광고 허용 페이지에서 차단 페이지로 App Router 이동할 때 기존 AdSense/Auto Ads DOM이 남던 문제를 발견했다. 허용→차단 경계에서 전체 문서를 다시 로드해 차단 URL이 광고 연결 없이 시작하도록 수정했고 실제 브라우저에서 script 0, slot 0을 확인했다.
4. 방법론이 주휴수당 계산기의 지원 상한을 주 50시간으로 잘못 설명하던 문구를 실제 엔진의 주 40시간 상한과 일치시켰다.
5. Publisher audit의 본문 1,200자/350자 기준을 제거했다. 빈 페이지 방지 최소 검사만 유지하고 route/sitemap, metadata, canonical, JSON-LD, 내부 링크, 광고 차단, 404 검사를 강화했다.

## 5. 404·브라우저·산출물 근거

- `/this-page-does-not-exist-260824`, `/calculators/not-real-calculator/`, `/random-test-path/`: 모두 HTTP 404.
